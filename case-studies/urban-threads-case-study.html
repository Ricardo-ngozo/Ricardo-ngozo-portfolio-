Urban Threads

A fashion-forward storefront concept that uses bold typography, full-bleed imagery, and a clean product grid to tell a brand story that converts.

What was the brief?

Urban Threads is a conceptual fashion brand project. The goal was to design and build a modern storefront landing page that felt like it belonged to a real premium streetwear label "” strong brand identity, product showcase, and a path to purchase.

The design challenge was making the page feel editorial and aspirational while still being functional as a shopping experience. Fashion brands live or die on their visual identity, so the UI had to communicate the brand before a user reads a single word.

What decisions did I make and why?

  • Full-bleed hero: The landing hero uses a full-viewport image with overlaid typography "” putting the product front and center and immediately establishing the brand's visual language.
  • Bold editorial typography: Large, confident headline text creates the fashion magazine feeling that streetwear brands rely on. It signals premium without needing luxury price tags.
  • Product grid with hover states: Each product card reveals a secondary view on hover "” showing an alternate angle or detail shot. This is a standard e-commerce pattern that increases engagement and reduces return rates.
  • Minimal color palette: Black, white, and one accent color. This keeps the product imagery as the visual focus and prevents the UI from competing with the clothes.
  • React component structure: Product cards, navigation, and layout sections are separate components "” making it easy to swap in real product data from a headless CMS or Shopify API.

Tools, technologies, and what I learned

Stack used

  • React (functional components)
  • CSS-in-JS for component styles
  • CSS Grid for product layout
  • Responsive images and art direction
  • Vercel for deployment

Key learnings

  • How brand identity translates to UI decisions "” every spacing choice, font weight, and color either supports or contradicts the brand voice.
  • E-commerce conversion patterns: what to put above the fold, how to sequence product information, and when to use a CTA versus letting the product speak.
  • How to build product card hover states that feel smooth and intentional rather than abrupt.
  • Image performance: large hero images need careful optimization "” lazy loading, next-gen formats, and responsive srcset "” to keep load times acceptable.

What would I do differently? What am I proud of?

I would connect the product grid to a real headless CMS "” Contentful or Sanity "” so the catalog can be updated without touching the code. That's how production fashion sites actually work, and wiring it up would make this a genuinely deployable template.

I'd also add a cart interaction with a slide-in drawer, size selection, and local cart state "” the core interaction loop of any real e-commerce experience.

I'm proud of the visual execution. The page has a real brand feel "” it looks like a site a fashion label would actually ship. That came from making deliberate design decisions rather than just laying out content, and it showed me how much design thinking matters when you're building for an audience that judges by aesthetics first.

Brand-first design

The layout hierarchy was built around the principle that the brand speaks before the product. Typography and image placement establish trust and aesthetic fit before the user consciously evaluates the clothes.
