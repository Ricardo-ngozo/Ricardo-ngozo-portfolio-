Case Study

Tesla Showcase

Building a premium landing page meant solving fluid scroll behavior while preserving crisp animation and a high-end brand presence.

HTML CSS Vanilla JS
Back to Projects Discover why
Full-screen hero and scroll-driven content sections with layered motion.

What was the brief?

The assignment was to recreate a high-performance product landing page with strong visual hierarchy, scroll-based navigation, and an immersive hero experience.

The main challenge was keeping motion smooth on entry while maintaining a crisp, brand-driven layout on mobile and desktop.

What decisions did I make and why?

  • Vanilla JavaScript: I chose plain JS for the interaction layer to keep bundle size minimal and keep every scroll transition predictable.
  • Scroll snap: using CSS scroll-snap-type for hero-to-section movement improved the feel and reduced custom scripting complexity.
  • Minimal animation: kept reveals subtle and deferred non-essential motion on smaller screens to preserve performance.
  • Accessible contrast: I prioritized text legibility over decorative effects so the page stayed functional across devices.

Tools, technologies, and what I learned

Tools and tech

  • HTML5
  • CSS animations
  • JavaScript event handling
  • Figma prototypes
  • Chrome Lighthouse

Lessons learned

  • How to build elegant scroll experiences without overloading the DOM.
  • Why fallback styles matter when animations are reduced or disabled.
  • How to layer gradients and imagery for a modern product presentation.

What would I do differently? What am I proud of?

I would add richer section-based animations triggered by IntersectionObserver and more robust keyboard navigation for anchor sections.

I'm proud of the polished hero composition and the responsive layout that keeps the design premium even on smaller screens. The site feels deliberate and uses motion only where it supports content.

Design direction

The page uses a restrained palette, spacious typography, and clean section cards so the product feel remains modern and luxurious.
