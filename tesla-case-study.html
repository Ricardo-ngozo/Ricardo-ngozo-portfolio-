Case Study

Interactive Quiz Widget

A group-built quiz project designed to deliver instant scoring, interactive feedback, and a mobile-friendly study experience.

JavaScript UX Design Form Interactions
Back to Projects View Live

What was the brief?

The goal was to build a quiz widget that could support varied question types, provide immediate correct/incorrect feedback, and remain easy to use on mobile.

Key challenges included keeping the interactions snappy, styling active states clearly, and preserving usability for learners under time pressure.

What decisions did I make and why?

  • Instant feedback: I added answer validation and state updates immediately after selection to keep the experience engaging.
  • Progress tracking: users can see their score updates in real time, which encourages completion and reinforces learning.
  • Mobile-first UI: buttons and cards were sized for touch, with clear spacing and accessible contrast.
  • Group collaboration: interaction patterns were aligned across team members to deliver a consistent experience.

Tools, technologies, and what I learned

Tools and tech

  • HTML5
  • CSS
  • JavaScript
  • Responsive design
  • Team collaboration

Lessons learned

  • How to make quiz feedback immediate without confusing the user.
  • Why clear visual states matter in a game-like learning interface.
  • How to structure JavaScript for form-based interactions.

What would I do differently? What am I proud of?

I would add question categories and save progress locally so users can return to the quiz later with their score preserved.

I'm proud of the crisp interaction design and clear mobile layout. The widget feels responsive and reliable while supporting a fast review workflow.

Interaction focus

The visual system was built around immediate action feedback, with strong button states and easy-to-scan question cards.
