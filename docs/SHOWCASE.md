## ✨ Animation Showcase

### CV Button: The Glow Effect

```
Idle State (Continuous Loop):
  
  Frame 0%:   ⭐ ✨ ✨        (Soft)
  Frame 25%:  ⭐ ✨ ✨ ✨      (Building)
  Frame 50%:  ⭐ ✨ ✨ ✨ ✨   (Peak glow)
  Frame 75%:  ⭐ ✨ ✨ ✨      (Fading)
  Frame 100%: ⭐ ✨ ✨        (Soft)
  
  Duration: 3 seconds (repeats forever)

Pulse Ring Effect (Sonar):
  
  Frame 0%:   ●               (Center, opaque)
  Frame 50%:  ◎               (Expanding)
  Frame 100%: ◯               (Fades away)
  
  Duration: 2 seconds (repeats forever)

Hover State (Reactive):
  
  Trigger: Mouse over button
  Action 1: Scale 0.95x → 1.08x (Expansion)
  Action 2: Lift 4px higher (Rise)
  Action 3: Glow intensifies (Highlight)
  Duration: 150ms (quick response)
```
