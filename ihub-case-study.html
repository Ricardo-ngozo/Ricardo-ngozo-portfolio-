Case Study

iHub Prototype

A group project prototype for iHub that emphasizes responsive learning paths, content cards, and onboarding clarity.

HTML CSS Grid Responsive Design
Back to Projects View Live

What was the brief?

The scope was a group prototype for iHub, aiming to communicate course discovery, mentorship connections, and community features in a polished interface.

The challenge was aligning multiple content modules into a clean, responsive layout that felt cohesive across desktop and mobile.

What decisions did I make and why?

  • Modular cards: I broke the prototype into reusable card components to make the layout easier to organize and scale.
  • Responsive grid: using CSS Grid allowed the page to reflow gracefully without losing content hierarchy.
  • Clear onboarding: I prioritized clear step flows so the user journey felt intuitive and approachable.
  • Group alignment: shared design tokens and spacing systems ensured consistency across team members.

Tools, technologies, and what I learned

Tools and tech

  • HTML5
  • CSS Grid
  • Responsive design
  • Figma collaboration
  • Design system thinking

Lessons learned

  • How to structure a group prototype with reusable interface patterns.
  • Why responsive content scaling matters for dashboard-heavy prototypes.
  • How to make onboarding feel approachable through visual hierarchy.

What would I do differently? What am I proud of?

I would expand the prototype into a small design system so each content module could be reused across more screens while staying visually consistent.

I'm proud of the layout clarity and how the prototype balances information density with whitespace. The result is a strong foundation for future iHub product pages.

Prototype strategy

The prototype aimed to reduce cognitive load by grouping related items, using section headers, and limiting color accents to key actions.
