Case Study

Netflix Experience

Rebuilding the Netflix homepage meant solving media discovery with a rich, scrollable visual grid while keeping animation performance smooth on all screens.

React UI Architecture API Integration

Hero layout demonstrating the dark streaming interface and media carousel.

What was the brief?

The goal was to recreate a polished streaming landing experience that felt familiar to Netflix users while focusing on horizontal carousel navigation, large media cards, and an accessible dark theme.

Key problems included keeping the interface responsive, preserving performance during card transitions, and making a dense catalog feel easy to scan.

What decisions did I make and why?

  • React component structure: I split the UI into reusable carousel, banner, and card components so the layout could scale cleanly and state could stay localized.
  • CSS grid + flex: used CSS Grid for the overall responsive page and flex layouts for carousel rows to ensure consistent spacing across breakpoints.
  • Static data layer: I began with seeded JSON instead of a full API, allowing the focus to remain on interaction design and layout polishing.
  • Motion economy: I kept subtle hover and transition effects, avoiding heavy animations on smaller screens to maintain smooth scrolling.

Tools, technologies, and what I learned

Tools and tech

  • React
  • CSS Grid / Flexbox
  • Responsive design
  • Figma for wireframing
  • Chrome DevTools performance audit

Lessons learned

  • How to organize component state for nested carousel data.
  • Why dark UI contrast and focus styles matter for accessibility.
  • How to balance visual richness with page speed.

What would I do differently? What am I proud of?

Next time, I would add a true search filter and use virtualization for long media lists so load time stays low even with hundreds of cards.

I'm proud of the final polished theme, the clean hero hierarchy, and the way the carousel feels cohesive across desktop and mobile. The layout retains the Netflix style without feeling like a shallow copy.

Visual problem solving

To reduce visual clutter, I focused on three layers: hero banner, row-based media stripes, and a soft backdrop. This allowed important content to stand out while preserving the cinematic brand feel.
