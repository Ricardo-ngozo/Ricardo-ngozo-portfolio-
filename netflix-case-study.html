Case Study

X (Twitter) Clone

Rebuilding the X feed meant balancing responsive social interactions with a polished timeline layout and strong visual hierarchy.

React Responsive Feed UI Replication
Back to Projects View Live

What was the brief?

The project required a polished X/Twitter clone experience with a focus on feed readability, intuitive reply states, and responsive post cards.

Core problems included keeping the timeline effortless to scan, preserving post interaction affordances, and making the UI feel native across screen sizes.

What decisions did I make and why?

  • Feed-first layout: I prioritized the timeline by using card groups that stay readable and consistent across desktop and mobile.
  • Interactive affordances: link-like post actions and hover states were added to make each card feel actionable without adding visual noise.
  • Responsive stacking: the design collapses gracefully to stacked panels on smaller screens while keeping author and content structure intact.
  • Minimal animations: motion was used only for hover feedback and post focus states to keep the experience fast.

Tools, technologies, and what I learned

Tools and tech

  • React
  • CSS Flexbox
  • Responsive design
  • Figma layout planning
  • Browser compatibility testing

Lessons learned

  • How to translate social feed motion into a stable responsive pattern.
  • Why information density matters in a timeline interface.
  • How to keep interactive post controls clear on touch devices.

What would I do differently? What am I proud of?

I would improve the clone by adding a real backend feed API and caching so the timeline can scale beyond a static dataset.

I'm proud of the crisp feed composition and the way the interface keeps a strong brand feel while staying clean and readable across devices.

Design problem solving

I aimed to maintain the recognizable X layout while reducing visual clutter through consistent spacing, subtle dividers, and clear user card hierarchy.
